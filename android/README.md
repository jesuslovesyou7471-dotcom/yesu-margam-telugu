# Android TWA project

This directory is reserved for the Bubblewrap-generated Android project.

Generate/update it with:

```bash
bubblewrap init --manifest="https://yesu-margam-telugu.hatchable.site/manifest-v14.json" --directory=android
bubblewrap update --manifest=android/twa-manifest.json
```

Do not commit keystores, passwords, or signing secrets.
